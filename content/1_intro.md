# Welcome to Physics 5350!

## Logistics and Overview

This is the course website for PHYS 5350 taught at UConn for the Fall of 2026. 

### How to use this website
This website has been compiled as Jupyter book from a github repository of interactive notebooks, markdown notes, and python scripts.

```{note}
The website is re-built each time an update is pushed to the github repository. 

In general, the course content for every week will be updated as the semester progresses.

If something is missing that you are expecting to see, try reloading the page. 

If that doesn't work, please let me know!
```

Please see the [course syllabus](./syllabus.pdf) for a comprehensive description of the course policies, deadlines, and assignments. 

You will be able to see what we cover in class by navigating to the "[Course Schedule](./3_schedule.md)" on the sidebar and selecting the relevant week. 

Each week will include the relevant pre-reading assignments, lecture content to follow along with, and the in-class exercises to turn in every week.  

Guidelines and skeleton code are provided for the problem sets under "[Problem Sets](./4_psets.md)" in the side menu.

```{tip}
Assigned work should be turned in and uploaded onto the relevant assignment submission location on HuskyCT.
``` 

#### Interactive Usage
You can interact with the code on this site in several ways:
+ By clicking on the download button in the upper righthand corner of the page to download an interactive notebook directly to your computer, modifying and running from there.
+ By clicking the power button to run the notebook from a remote binder server and executing the cells, though this does not allow you to modify the code. (Connection to the server takes some time, so this is not a sure bet.)
+ By copy pasting cells of code directly into your editor of choice and going from there.
