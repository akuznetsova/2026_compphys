```{exercise} Check-in Question
:label: ex_11-1
:nonumber:
Since we want to compute the decay iteratively, we need to generalize the probability to be in terms of decay over some time interval $t \rightarrow t + \Delta t$. What is $p(\Delta t)$?
```

```{solution} ex_11-1
:label: sol_11-1
:nonumber:
:class: dropdown
Since the exponential relationship is just a solution to an initial value problem, so $N_0$ always reflects the starting abundance at some relative time ($\Delta t$ is the same as $t$ if our initial time is $0$). 

Formally:
$$N_0 = N(t) 2^{t/\tau}$$
$$ N(t + \Delta t) = N_0 2^{-(t+\Delta t)/\tau} =  N(t) 2^{t/\tau} 2^{-(t+\Delta t)/\tau} = N(t) 2^{-\Delta t / tau}$$

So, trivially:
$$p(\Delta t) = 1 - 2^{-\Delta t/\tau}$$
```
