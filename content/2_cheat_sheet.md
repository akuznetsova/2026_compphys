# Resources

Below is a set of links to external resources that may be useful for various aspects of this course. They are all freely available and accessible online. 
There is a lot of coding content on the web, of varying levels of quality. Googling around can yield answers, but often not appropriate context or explanation.
These resources are provided as more self-contained or curated references. 

## General Python
+ [Think Python](https://allendowney.github.io/ThinkPython) by Allen Downey.
    - (Basic) introduction to Python, available as a pdf or guided Jupyter notebook tutorials. **If you don't have much experience with Python, highly recommended that you supplement the first two weeks of the course by working through this resource.**
+ [Official Python Tutorial](https://docs.python.org/3/tutorial/) by Python devs.
    - A reference from the source itself, good for looking up definitions and use cases. A bit long for a tutorial.
+ [Programming with Python](https://swcarpentry.github.io/python-novice-inflammation/index.html) by Software Carpentry.
    - A guided set of lessons to walk through an applied example. 
+ [Whirlwind Tour of Python](https://github.com/jakevdp/WhirlwindTourOfPython) by Jake Vanderplas.
    - (Basic) python concepts shown with a set of jupyter notebooks, good for additional examples.
+ [Python Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook) by Jake Vanderplas.
    - (Applied) python concepts for data analysis and data science, as a free book. An introduction to external libraries for scientific computing: numpy, matplotlib, etc.
+ [Scientific Computing with Python](https://github.com/jrjohansson/scientific-python-lectures) by Robert Johansson.
    -  (Applied) python concepts for data analysis and data science, as a set of demo notebooks. Example usage of external libraries for scientific computing.
+ [Google's Python Class](https://developers.google.com/edu/python) by Nick Parlante.
    - Materials from a two-day workshop at Google for Python programming. Geared towards those with some prior programming experience.
+ [Python for Scientific Computing](https://sbu-python-class.github.io/python-science/01-python/installing.html) by Michael Zingale
    - Online course notes for Mike Zingale's scientific computing course at Stonybrook.

## Unix and the Command line
+ [The Unix Shell](https://swcarpentry.github.io/shell-novice/index.html) by Software Carpentry.
    - A guided set of lessons around navigating the command line.
+ [Unix Tutorial for Beginners](https://info-ee.surrey.ac.uk/Teaching/Unix/) by Univ. of Surrey.
    - A beginners guide to Unix OS commands.
+ [Bandit War Games](https://overthewire.org/wargames/bandit) by OverTheWire
    - A set of "games" to teach the principles of making remote connections and navigating filesystems on the command line. Nice if you enjoy gamification.

## Computing for Physics
+ [An introductory course for Computational Physics](https://farside.ph.utexas.edu/teaching/329/lectures/lectures.html) by Richard Fitzpatrick.
    - A set of html notes on computational physics concepts. Written for programming in C, but concepts transferrable.
+ [Numerical Recipes](https://numerical.recipes/book.html) by William H. Press et al. 
    - One of the classics. Full 3rd edition hosted by the authors as pdfs. Written for C++, but concepts transferrable.

## Misc.
+ [Project Euler](https://projecteuler.net/about)
    - A set of computational puzzles for practicing algorithmic thinking. (A bit pretentious.)
